# Telco Customer Churn Analysis

## Overview

This project explores customer churn in a telecommunications dataset using Python-based exploratory data analysis (EDA).

The analysis investigates whether customer characteristics, service subscriptions, and account-related factors are associated with customer churn.

### Research Question

> Which customer characteristics, service subscriptions, and account-related factors appear most strongly associated with churn in the Telco Customer Churn dataset?

## Tools Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis

The exploratory analysis included:

- Dataset structure and variable inspection
- Data type and missing-value checks
- Duplicate detection
- Data preparation and cleaning
- Churn distribution analysis
- Customer demographic analysis
- Service subscription analysis
- Contract and payment method analysis
- Tenure and charge analysis
- Correlation analysis

## Key Findings

The analysis identified several variables that showed notable associations with customer churn, including:

- Month-to-month contract type
- Shorter customer tenure
- Higher monthly charges
- Fibre-optic internet service
- Electronic-check payment method

The analysis also identified lower churn associations with factors such as longer-term contracts, longer tenure, online security and technical support.

These findings represent associations observed in the dataset and should not be interpreted as evidence of direct causation.
